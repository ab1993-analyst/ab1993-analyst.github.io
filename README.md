 1. Problem:
            Cyclistic wants to convert casual riders into annual members.

 2. Goal:
            Identify behavioral differences between casual riders and members.

 3. Tools:
          - SQL (data extraction & cleaning)
          - Google Sheets (analysis + visualization)

 4. Analysis:
          - Compared ride duration.
          - Analyzed weekday vs weekend usage.
          - Studied monthly trends.

 5. Key Insight:
            Casual riders use bikes more on weekends and for longer rides → recreational use
            Members use bikes consistently → commuting behavior.

 6. Recommendation
            Target casual riders with weekend membership promotions and commuter discounts.
